
Bowling DP, use suffixes:

* Subproblems: B(i) = max score starting with pins i, i+1, ... n-1
               for 0 <= i <= n
* Relation:
  ~ Local brute force: what would happen:
      o skip pin
      o hit pin
      o hit 2 pins
  ~ Reduce to smaller suffix and recurse B(i+1) OR B(i+2)
  ~ B(i) = max{B(i+1), B(i+1)+vi, B(i+2) + vi*vi+1}
* Topo order: Decreasing i (for i = n, n-1, ..., 0)
* Base cases: B(n) = 0
* Original: B(0)
* Time: (memoization) θ(n)
